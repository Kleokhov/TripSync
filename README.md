# TripSync

TripSync is a full-stack travel planning app built for the way real friend groups actually travel — especially when people are studying abroad, living in different cities, and each bringing a different travel style to the table.

It was inspired by friends planning study-abroad trips across different places and with different vibes: some wanted museums and cafes, others wanted beaches and nightlife, and everyone wanted a plan that felt collaborative instead of chaotic. TripSync turns that into a smooth, modern trip-planning experience.

## What it does

- Helps users discover cities and countries through an intuitive experience
- Surfaces travel recommendations and destination details
- Lets users build a shared shortlist of places to visit
- Generates personalized itineraries based on trip length, preferred categories, and things to avoid
- Makes group trip planning feel more organized, visual, and enjoyable

## Why it stands out

This project sits at the intersection of product design, user experience, and software engineering. It’s not just a travel app — it’s a practical solution to a real social problem: making group travel decisions easier when everyone has different interests and constraints.

## Tech stack

- Frontend: React, TypeScript, Vite, React Router
- UI: modern component-based interface with Radix-style primitives and reusable UI patterns
- Backend: Node.js + Express.js
- Data layer: PostgreSQL-backed API architecture
- Testing: Jest
- Tooling: npm, Vite, Nodemon, CORS

## Architecture

- A React frontend for browsing destinations and planning trips
- An Express backend exposing REST endpoints for cities, countries, recommendations, and itinerary generation
- A modular, route-driven structure that keeps the experience scalable and maintainable
- A component-based UI designed for a polished multi-page travel workflow

## Getting started

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend
cd backend
npm install
npm run dev
```
